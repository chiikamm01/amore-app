# Video background

Place your background video here:

- **`background.mp4`** – used as the full-page background (autoplay, loop, muted).

The video is set to `object-fit: cover` so it fills the viewport on all devices. The dark gradient overlay (`.image`) stays on top so text remains readable.

To use a different path or filename, update the `<source src="...">` in `src/components/figma/IpadPro.jsx`.
